Preguntas frecuentes

Todo lo que necesitas saber

Respuestas rápidas antes de instalar QuickPaste.

¿Qué es QuickPaste?

QuickPaste es una extensión para Chrome que permite guardar plantillas, respuestas y textos frecuentes para reutilizarlos rápidamente mediante atajos de teclado.

¿Qué son las variables dinámicas?

Son campos personalizables que puedes incluir dentro de una plantilla. Por ejemplo, puedes crear un mensaje con variables para el nombre del cliente, servicio, precio o cualquier otro dato que necesites completar.

¿Cómo funciona la tecla Tab?

Cuando utilizas una plantilla con varias variables, introduces el primer dato y pulsas Tab para pasar directamente al siguiente campo. Así puedes completar un mensaje personalizado de forma rápida y sin utilizar el ratón.

¿Puedo crear mensajes personalizados?

Sí. Puedes combinar texto fijo con variables dinámicas para crear mensajes diferentes cada vez utilizando la misma plantilla.

¿Dónde puedo utilizar QuickPaste?

QuickPaste está diseñado para reutilizar textos en páginas web y resulta especialmente útil para correo, atención al cliente, ventas, administración y cualquier tarea repetitiva que realices desde Chrome.

¿QuickPaste es gratis?

La instalación de QuickPaste se ofrece actualmente de forma gratuita.

¿Cómo puedo instalar QuickPaste?

Haz clic en cualquiera de los botones “Instalar QuickPaste gratis” para acceder directamente a la ficha de QuickPaste en Chrome Web Store.
